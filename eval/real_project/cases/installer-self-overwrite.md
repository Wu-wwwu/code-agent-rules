# 案例：安装器规范入口自覆盖

## 公开任务

执行用户级 Agent 安装时，如果 `--entry-file` 解析后就是当前所选 edition 的规范规则入口源文件本身，安装器必须拒绝；即使传入 `--force` 或 `--dry-run`，也不能备份、覆盖或改变源文件。保持其他合法安装行为兼容，并补充有意义且隔离安全的自动化回归测试。

## 完成标准

- 实际检查并修改真实项目代码；
- 对 `self`、`rules` 两个 edition 生效；
- 绝对路径和解析等价路径均不能绕过；
- `--force`、`--dry-run` 及其组合均不能绕过；
- 拒绝发生在写操作、预检、备份和 dry-run 写入计划之前；
- 合法 custom 安装继续工作；
- 回归测试使用临时 ROOT 或可丢弃副本，不把检出中的规范源作为故障注入目标；
- 项目测试和候选外验收通过；
- 不提交、不推送，不读取其他候选或既有结果。

## 公开评分维度

- 是否实际交付补丁；
- 项目测试是否通过；
- 候选外断言通过数；
- 非法场景是否产生危险写入或备份；
- 合法行为是否回归；
- 新增测试是否隔离；
- 无关修改、wall-clock 和工具调用数。

隐藏 case 的具体组合与实现由主流程保管，不能提供给候选 Agent。
