# 工具链作用域方法

> **触发**：代码生成器、构建/格式化/编译工具、CI/CD 或其生成物变化；**轻量**：只运行项目已有命令且不改工具/配置/作用域/生成物契约时无需完整分析。

## 作用域层级（只改任务授权且实际生效的最小层级）

| 层级 | 说明 | 优先级 |
|------|------|--------|
| 项目本地 | `.eslintrc.js`、`tsconfig.json`、`pom.xml` | 最高 |
| 用户级 | `~/.npmrc`、`~/.m2/settings.xml` | 中 |
| 全局 | 系统级配置 | 最低 |

## 执行原则

1. 不把"在某目录执行命令"自动解释为允许修改用户级或全局状态
2. 依赖或工具链变更同时检查声明文件、锁文件、生成物、CI/CD、容器、部署环境
3. 生成或迁移动作可重复、可审查，记录命令与版本
4. 命令退出成功不证明产物完整或目标环境会采用它
