# 可选项目文档方法

> **触发**：专项方法准备读写目标项目 `documents/*.md`；**定位**：documents/ 是可选长期记忆，非默认前置；**写入模板**：需要最小模板时加载 `methods/templates.md`。

## 读取前检查

1. 确定目标项目根目录；不得把规则仓库示例目录、根目录 `/documents/` 或其他项目文档当作当前项目事实。
2. 只检查当前动作需要的文件，不因进入项目就创建或全文读取目录。
3. 目标文件分类：
   - **有效**：有来源，适用于当前项目与范围（唯一可作项目事实）
   - **缺失**：目录或文件不存在
   - **示例/占位**：含 `EXAMPLE`/`示例`/`待替换` 等标记或无真实来源（仅作格式参考）
   - **过期/冲突**：与代码、配置、Schema、测试、运行结果或用户说明不一致
4. 示例/占位/冲突内容只能作格式参考或待核实线索。

## 文档职责

| 文件 | 用途 | 主要来源 |
|------|------|----------|
| `documents/project-doc.md` | 项目目标、用户/场景、范围、主要功能与成功标准 | 用户确认、README、可验证产品行为 |
| `documents/architecture.md` | 系统边界、模块职责、依赖方向、入口与运行/部署拓扑 | 代码、配置、部署文件、运行证据 |
| `documents/tech-stack.md` | 当前实际使用的语言、框架、存储、工具链及版本来源 | 声明文件、锁文件、配置、构建结果 |
| `documents/data-flow.md` | 关键功能从输入到输出的数据、状态和外部依赖路径 | 调用、Schema、查询、消息、测试、追踪 |
| `documents/business-rules.md` | 有证据锚点的业务规则 | 代码、Schema、测试、用户确认 |
| `documents/decision-log.md` | 需跨会话回查的技术决策及状态 | 决策记录、提交历史、用户确认 |
| `documents/coding-standards.md` | 项目特有且可由工具/代码验证的编码与测试约定 | lint/format/test 配置、代码惯例、CI |
| `documents/glossary.md` | 术语、代码实体、存储名之间的已验证映射 | 代码、配置、Schema、用户确认 |

**缺失 ≠ 项目没有对应物**：只表示持久化记录不可用。需要当前上下文时加载 `methods/project-context.md`；只有内容已验证且有跨会话复用价值时才写回。

## 缺失时的降级

- 目标/架构/技术栈/数据流/编码标准缺失：从用户说明、README、代码、配置、声明/锁文件、测试、运行与部署证据构造最小事实；不得为补齐目录阻塞任务。
- `business-rules.md` 缺失：从用户确认、业务资料、代码判断、Schema 和测试定位目标行为；无可验证依据时暂停语义裁决，不得推测。
- `decision-log.md` 缺失：声明"无可用的决策档案，无法证明不存在历史决策"；再从提交历史、讨论记录、代码注释、当前证据补充检索；仍无记录则按当前证据继续，高影响冲突处请求确认。
- `glossary.md` 缺失：按 `methods/data-entity-analysis.md` 用用户用词、代码标识、Schema、表与检索扩展定位；不停检索，也不从名称引入现实领域语义。

## 按需初始化（仅同时满足才创建/更新）

1. 任务需要可复用、跨会话的项目记忆
2. 已有至少一条可定位的真实证据，或即将记录满足建档条件的决策
3. `documents/` 在本次授权范围内；纯查询、只读审查或范围不明时不写入，可返回待落盘草案请求确认

步骤：创建 `documents/`（仅当不存在）→ 只建当前需要的单个文件 → 写最小标题、证据边界、必要表头，不复制演示数据 → 立即写入本次已验证条目及来源，无真实内容不建空壳 → 回读核对，推断必须标记"待确认"。

## 最小模板

写入 `documents/*.md` 需要最小模板时，加载 `methods/templates.md` 按需选择；模板不代表已补齐事实，写入后立即回读核对。

## 更新边界

- 当前实现以代码、配置、Schema、运行结果为准；目标行为以有效业务依据和用户确认为准
- 稳定事实也必须附来源；实现变化后复核对应记录
- 不把同名数据实体解释为现实物品或自然概念，除非现实语义有明确证据且任务需要
- 文档与实现冲突先标记冲突，不静默覆盖任一方
- 项目已有自定义结构时沿用，只补最小字段
- 规则条目 `R-<领域>-<序号>`、决策条目 `D-<YYYYMMDD>-<序号>`；不编造日期/状态/owner/来源/ID
- 写入后立即回读核对；模板不代表已补齐事实
