# 安全控制

> **进入**：认证、授权、角色、权限、密钥、个人/财务数据、外部输入、命令执行、文件路径、网络访问或生产环境；纯说明且不改变行为时跳过。

1. 明确资产、主体、信任边界、输入来源、执行权限和失败后果；安全语义不清且会改变访问结果时暂停。
2. 默认最小权限和拒绝，在服务端或可信边界执行授权；外部输入按上下文校验、规范化和编码，避免拼接命令、查询或路径。
3. 密钥、令牌和连接信息不得硬编码、提交或写入日志；敏感信息只记录必要且脱敏的内容。
4. 破坏性测试、迁移、备份、权限变化和故障注入使用临时目录、临时数据库、沙箱或可丢弃副本；无法建立隔离时不执行。
5. 生产写入、权限提升、公开暴露、历史覆盖或安全策略放宽前，先只读检查/预演，说明影响与恢复方式并取得明确授权；同时验证允许、拒绝、越权、注入、泄露和错误信息路径。

工具成功不等于安全完成；疑似凭据泄露时停止传播或展示，报告影响范围并按项目流程撤销、轮换和审计。安全要求完成或已明确阻塞与解除条件后退出，不替代破坏性分析或业务规则。
