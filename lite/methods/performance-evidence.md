# 性能证据方法

> **触发**：性能/容量/延迟/吞吐/资源消耗是目标或方案依据；**轻量**：仅作背景描述且不作优化结论时无需基线，一旦支撑方案或完成声明必须执行。

## 基线测量（优化前必须记录）

- 环境：CPU/内存/数据库版本/数据规模
- 当前耗时：P50/P95/P99
- 执行计划：全表扫描/索引扫描/嵌套循环（CPU/内存/异步场景另记录对应采样）

## 验证要求

- 用相同工作负载比较
- 没有可比测量时不得声称优化完成
- 输出测量结果和对比数据

## 示例格式

```
[基线测量]
- 环境：4CPU/8GB，PostgreSQL 15，10万条数据
- 当前耗时：2.3s（P95）
- 执行计划：全表扫描

[优化后]
- 优化后耗时：12ms（P95）
- 执行计划：索引扫描
- 提升：99.5%
```
