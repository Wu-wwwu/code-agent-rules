# 项目文档示例

本目录提供可选的最小项目文档模板。安装器可以预置模板；实际读取、创建和更新遵循当前所选规则版本的项目文档门禁。

> **注意**：目录中的示例业务场景、概念标识、存储名称和规则编号均为演示数据，不代表当前仓库存在对应业务代码。示例不预设编程语言、框架、数据库或架构风格。接入真实项目时，只在任务需要且内容具有跨会话复用价值时按需更新；必须根据代码、配置、测试、运行结果和用户资料替换，无法验证的信息标注“需用户提供”或“待确认”。

| 文档 | 用途 |
|------|------|
| `project-doc.md` | 项目目标、用户场景、范围、主要功能与成功标准 |
| `architecture.md` | 系统边界、模块职责、依赖方向与运行拓扑 |
| `tech-stack.md` | 当前技术、版本证据、工具链和作用域约束 |
| `data-flow.md` | 功能入口到输出的数据、状态、外部依赖与验证接缝 |
| `decision-log.md` | 技术决策索引、记录与待决问题 |
| `coding-standards.md` | 从实际代码观察到的项目规范 |
| `business-rules.md` | 有证据支持的业务规则 |
| `glossary.md` | 业务术语、代码实体与数据表映射 |
