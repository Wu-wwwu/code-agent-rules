# 项目文档示例

本目录提供可选的最小项目文档模板。安装器默认不复制模板；需要时使用项目安装的 `--include-documents` 显式复制；实际读取、创建和更新遵循当前所选规则版本的项目文档门禁。

> **注意**：目录中的示例业务场景、概念标识、存储名称和规则编号均为演示数据，不代表当前仓库存在对应业务代码。示例不预设编程语言、框架、数据库或架构风格。接入真实项目时，已有文档受实现或配置变更影响应在完成验证后按当前事实同步；新建文档仅在任务需要、内容具有跨会话复用价值且处于授权范围时进行。必须根据代码、配置、测试、运行结果和明确的目标/约束依据替换，无法验证的信息标注“需用户提供”或“待确认”。

模板元数据含义：`document_status: template` 与 `project_facts: none` 表示内容不可作为项目事实。接入真实项目并完成证据核验后，才可将其更新为 `document_status: active`、`project_facts: verified`，并为事实保留来源；未完成核验时不要只删除标记。
| 文档 | 用途 |
|------|------|
| `project-doc.md` | 项目目标、用户场景、范围、主要功能与成功标准 |
| `architecture.md` | 系统边界、模块职责、依赖方向与运行拓扑 |
| `tech-stack.md` | 当前技术、版本证据、工具链和作用域约束 |
| `data-flow.md` | 功能入口到输出的数据、状态、外部依赖与验证接缝 |
| `decision-log.md` | 技术决策索引、记录与待决问题 |
| `coding-standards.md` | 从实际代码观察到的项目规范 |
| `business-rules.md` | 有证据支持的业务规则 |
| `glossary.md` | 业务术语、代码实体与数据表映射 |
