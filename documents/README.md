# 项目文档示例

本目录展示 `/rules/document-init.md` 所定义的最小项目文档结构。

> **注意**：目录中的示例业务场景、概念标识、存储名称和规则编号均为演示数据，不代表当前仓库存在对应业务代码。示例不预设编程语言、框架、数据库或架构风格。接入真实项目时，必须根据代码、配置和用户提供的业务资料替换；无法验证的信息标注“需用户提供”。

| 文档 | 用途 |
|------|------|
| `project-doc.md` | 项目定位与目录概览 |
| `architecture.md` | 分层、模块边界与依赖方向 |
| `tech-stack.md` | 语言、框架、数据库与依赖版本 |
| `data-flow.md` | 入口到出口的数据链路 |
| `decision-log.md` | 技术决策索引、记录与待决问题 |
| `coding-standards.md` | 从实际代码观察到的项目规范 |
| `business-rules.md` | 有证据支持的业务规则 |
| `glossary.md` | 业务术语、代码实体与数据表映射 |
