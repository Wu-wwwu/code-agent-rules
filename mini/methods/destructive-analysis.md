# 破坏性分析

> **触发条件**：涉及数据删除/覆盖、用户或角色权限修改、配置覆盖、有副作用的外部 API 调用、公开 API 请求/响应变化、数据库 Schema 或共享数据契约变化。
> **复用条件**：复用前逐项比较本轮与前轮已确认的变更元素清单；只有本轮清单相同或为其严格子集，且授权仍有效、契约/环境/风险/迁移与回退条件均未变化时才能复用。

变更元素清单至少包括：目标环境；操作类型；数据、表、列、实体、文件和配置键；API、Schema 与下游消费者；主体、角色和权限；外部系统及副作用；数据范围或数量级；迁移与回退方式；用户授权条件。新增或改变任一元素都重新分析；达到高风险时重新确认。

## 项目化影响画像

触发词只表示需要分析，不直接决定风险级别。分级前按当前变更追踪：

- **代码**：入口、调用方、权限与校验边界、并发/幂等控制、写入点、下游消费者和验证接缝；
- **数据**：权威来源、传输与存储表示、影响范围、持久化与共享程度、可恢复性及下游派生数据；
- **流程**：前后业务步骤、状态变化、人工或自动节点、外部副作用、补偿路径和故障可见性；
- **关键资源**：依据项目代码、配置、Schema、流程、测试或用户资料，识别错误修改、泄露、越权、不可用会造成显著损害的资源，不按通用行业词表预设。

记录受影响资源、代码/数据/流程路径、失败后果、影响范围、发现方式、恢复方式和证据。下表的客观高风险条件是最低门槛：项目画像可以基于证据升级，但不得用“项目侧重点不同”把已命中的高风险条件降级。

## 变更分级

逐项检查全部条件，按命中的最高级别处理；可回滚性只能改善回退方案，不能抵消数据丢失、安全削弱、公开契约破坏或不可逆外部副作用。

| 级别 | 判定条件 | 要求 |
|------|----------|------|
| 非破坏性 | 仅透明扩展；不改变既有消费者行为、已有数据、安全边界或外部状态 | 简要记录并验证兼容性 |
| 低 | 只影响隔离、可丢弃或可再生对象；回退已验证；不涉及持久化/共享数据、安全边界或公开契约 | 输出影响清单并验证回退 |
| 中 | 需要内部消费者、配置或部署适配，但不导致数据丢失、安全放宽、公开契约不兼容或不可逆生产副作用 | 输出分步迁移与回退方案 |
| 高 | 删除/覆盖不可丢弃的持久化、共享、用户或生产数据；可能丢失或使数据不可读的 Schema 变更（如删除表/列、缩窄字段）；权限提升或安全策略放宽；不兼容地删除/改变公开 API 或共享契约；生产写入、历史覆盖或不可逆外部副作用；可能造成业务中断 | 输出准确影响清单、完整迁移与回退方案，取得明确用户确认后再执行 |

无法证明满足较低级别全部限制时，不得降到该级；信息不足且可能命中高风险时先暂停并补证据。

## 授权门禁与状态推进

高风险动作执行前必须展示待授权的变更元素清单、目标环境、预期影响、迁移步骤、回退方式和无法回退部分，并取得覆盖这些内容的明确确认；沉默、含糊回复或仅确认目标不等于授权执行。

- **确认**：记录获批范围和条件，返回 agent.md 执行循环的“选择”，只执行获批范围内的最小动作。
- **修改要求**：更新变更元素、方案和风险级别；仍为高风险时重新确认。
- **拒绝**：不执行受保护动作，提供安全替代方案；没有可行替代时标记阻塞。
- **未回复或含糊回复**：保持暂停，不执行受保护动作。
- **授权后发生变化**：目标环境、操作类型、变更元素、数据范围、风险、迁移或回退条件任一变化，原授权失效并重新分析；达到高风险时重新确认。

## 事前预测

输出数据/接口/流程/性能/安全破坏预测清单。预扫描对象：
- 本项目：表 / API / 模块 / 共享代码 / 共享配置
- 外部依赖：上游 changelog、release notes 中的 breaking change
- 生成物：迁移文件、锁文件、代码生成产物

## 扩展-收缩迁移模式

宽重构（爆炸半径大）不得一次性切换：

1. **扩展**：新增与旧形态并存
2. **分批迁移**：按包/目录分批切换，每批独立验证
3. **收缩**：确认无残留后删除旧形态

```python
# [破坏性能力] 类型：数据删除 / 表结构变更 / 共享配置

```

## 累积警告

多个风险项是重新评估信号，不按数量机械折算级别。只有风险之间存在相互作用、共享故障域，或累积后果经证据达到更高级别时才升级。
