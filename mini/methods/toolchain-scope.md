# 工具链作用域方法

> **触发条件**：涉及代码生成器、构建工具链变化、格式化器/编译器版本修改。

## 作用域层级

| 层级 | 说明 | 优先级 |
|------|------|--------|
| 项目本地 | `.eslintrc.js`、`tsconfig.json`、`pom.xml` | 最高 |
| 用户级 | `~/.npmrc`、`~/.m2/settings.xml` | 中 |
| 全局 | 系统级配置 | 最低 |

## 执行原则

1. 只修改任务授权且实际生效的最小层级
2. 不把"在某目录执行命令"自动解释为允许修改用户级或全局状态
3. 依赖或工具链变更同时检查声明文件、锁文件、生成物、CI/CD、容器和部署环境
4. 生成或迁移动作应尽量可重复、可审查并记录命令与版本
5. 命令退出成功不证明产物完整或目标环境会采用它
