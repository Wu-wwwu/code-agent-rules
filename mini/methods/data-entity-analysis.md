# 数据实体与表示变换

> **进入**：需跨类型、Schema、表或序列化格式归并实体、推导关系或追踪变换。单个已知构件的局部查阅跳过。

- 区分代码构件、跨表示的数据实体和现实对象；名称只用于检索，不用行业常识补全字段、关系、生命周期或规则。
- 从类型、字段、键、约束、查询、映射、输入输出、显式转换、测试或用户确认建立关系；名称相似不证明同一实体，名称不同也不证明不同。
- 证据不足时保持分离并标记未知；需要跨表示追踪时使用中性标识。
- 只记录实际存在的路径：`来源/创建 → 校验/补全 → 变换 → 持久化/传递 → 输出`，注明表示、字段/约束变化及证据位置。

已定位任务所需表示、关系和变换，剩余未知不影响当前结论时退出。
