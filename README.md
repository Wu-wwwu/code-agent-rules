# Code Agent Rules

> 让 AI Coding Agent 依据代码和文档进行编码和修复问题。

## 这是什么

一个可以被 AI Coding Agent 加载的**规则集**。它不是给人类读的编码规范文档，而是直接嵌入 Agent 工作流的**硬约束**：

- 什么能改、什么不能改
- 改动前先查什么文档、做什么评估
- 遇到 Bug 按什么流程诊断
- 什么时候该抽象、什么时候不该抽象
- 业务逻辑怎么分析、数据流怎么追踪

把 `rules/` 中的规则文件和 `documents/` 中的项目文档结构放到项目里，Agent 就会照章办事。不再需要每次都口头提醒。

## 目录结构

```text
.
├─ rules/        # Agent 行为规则、分析方法和编码约束
│  └─ agent.md   # 规则总入口；agent.md 本身位于 rules 文件夹
├─ documents/    # 项目事实、架构、业务规则、数据流和决策记录示例
└─ README.md     # 本规则仓库说明
```

## 规则清单

| 文件 | 定位 | 核心内容 |
|------|------|----------|
| `rules/agent.md` | 循环控制总纲 | 任务状态恢复、风险分级、能力路由、动作校验、暂停条件和循环控制 |
| `rules/business-analysis.md` | 业务决策 | 变更影响分析、决策四步框架、冲突回查、优先级体系 |
| `rules/data-flow-methodology.md` | 数据追踪 | 六步追踪法、固定推导顺序、节点标注规范 |
| `rules/data-structure-analysis.md` | 数据建模 | 实体识别、关系建模、字段推导、索引策略、写入策略阶梯 |
| `rules/destructive-analysis.md` | 风险控制 | 变更分级、事前预测、事中检测、扩展-收缩迁移模式 |
| `rules/diagnosing-bugs.md` | 排错流程 | 反馈回路→复现最小化→可证伪假设→插桩→修复→清理 |
| `rules/document-init.md` | 文档体系 | 8 类项目文档的创建时机、内容基准、初始化原则 |
| `rules/oop-principles.md` | 编码规范 | 抽象时机、DDD/OOP/AOP/FP 范式及安全与日志约束 |

`documents/` 下提供 8 类项目文档的最小示例。示例用于展示结构和写法，接入实际项目后必须依据代码与真实业务资料替换。

## 怎么用

在 AI Coding Agent 的系统提示或项目配置中引用 `rules/` 下的文件，并把 `documents/` 放在项目根目录。以 Cline 为例，可将规则文件配置为自动加载，并以 `rules/agent.md` 作为总入口。其他 Agent 平台对应机制类似。

Agent 会在自身的观察、执行和反馈长循环中加载这些规则。`agent.md` 不替代具体平台的工具调度，而是在循环关键位置提供统一约束：

```
任务开始/恢复
   ↓
校准目标、成功标准、状态和风险
   ↓
加载下一动作所需的最小知识
   ↓
选择并执行一个可验证动作
   ↓
校验实际结果并更新上下文
   ↓
继续 / 暂停 / 阻塞 / 回退 / 完成
```

改动风险决定每轮需要加载的规则和检查深度：轻微改动可直接执行；常规改动增加相关文档和决策回查；重大改动增加完整破坏性分析与用户方案确认。

## 设计原则

**风险驱动**。改动风险越大，流程越重；风险越低，流程越轻。不确定时自动升级。

**循环校验**。工具调用成功不等于任务步骤成功；每个逻辑动作后都要比较预期和实际，并据此更新下一轮状态。

**按需加载**。Agent 不全文通读文档，而是在每轮决策前只加载下一动作所需的规则、项目事实和代码证据。

**职责单一**。`agent.md` 决定何时做、调用谁和何时暂停；专项规则定义具体方法；`documents/` 记录当前项目事实。

**跨 Agent 可移植**。规则使用读取、搜索、修改、执行和验证等抽象行为，不绑定特定 Code Agent 的工具名称或内部实现。

**避免过早抽象**。抽象时机以 `rules/oop-principles.md` 为唯一来源。

**证据分层**。当前实现以代码、配置和运行结果为准；目标行为以用户确认的需求、业务规则和有效决策为准。两者冲突时显式标记，不擅自裁决；无法推导的内容标注“需用户提供”。

## 适用场景

适合嵌入任何使用 AI Coding Agent 的团队项目，作为 Agent 行为的统一标准。
