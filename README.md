# Code Agent Rules

AI 编码 Agent 的行为规范与项目文档体系，定义了 Agent 在项目中如何高效、安全地进行代码理解和修改。

## 目录

| 文件 | 说明 |
|------|------|
| `agent.md` | Agent 核心行为规范：任务分级、能力注册表、编码原则、上下文维持 |
| `business-analysis.md` | 业务分析与决策框架：变更影响分析、决策框架、回查机制 |
| `data-flow-methodology.md` | 数据流推导方法论：六步追踪法、节点标注、存储规范 |
| `data-structure-analysis.md` | 数据结构分析：实体识别、关系建模、字段推导、索引策略、写入策略阶梯 |
| `destructive-analysis.md` | 破坏性分析：变更分级、事前预测、事中检测、扩展-收缩迁移模式 |
| `diagnosing-bugs.md` | 疑难 Bug 诊断：六阶段诊断流程（反馈回路→复现→假设→插桩→修复→清理） |
| `document-init.md` | 项目文档体系初始化规范：文档清单、内容基准、初始化原则 |

## 核心设计理念

### 风险分级自适应
根据改动影响范围自动适配流程复杂度：
- **轻微改动**：意图确认 → 直接修改
- **常规改动**：意图确认 → 文档检索 → 决策回查 → 修改
- **重大改动**：意图确认 → 文档检索 → 决策回查 → 破坏性分析 → 方案确认 → 修改

### 能力注册表
Agent 根据任务类型按需调用对应能力文档，不全文通读，精准定位。

### 抽象原则（三次法则）
- 第一次出现：直接写，不抽象
- 第二次出现：允许重复，标记关注
- 第三次出现：提取公共逻辑
