# Code Agent Rules — Self 独立版

> 规范 AI Coding Agent 行为，提示/补充外部认知。

默认只加载 [`core.md`](./core.md)；本目录中的其他文件是触发式能力模块，不应全部预载。

| 触发场景 | 加载模块 | 解决的问题 |
|----------|----------|------------|
| 长任务、跨模块、上下文恢复、目标变化 | [`context.md`](./context.md) | 项目认知、运行态恢复、边界和影响闭环 |
| 偶发、复杂或无法稳定复现的 Bug | [`diagnosis.md`](./diagnosis.md) | 反馈回路、可证伪假设、插桩和回归 |
| API、Schema、数据、共享配置、全局状态或执行顺序、上游依赖 major 升级或弃用到期、生成工具链或不可逆变更 | [`change.md`](./change.md) | 兼容、迁移、配置作用域、生成物、防护、回退和事后核验 |
| 权限、认证、敏感信息、依赖或执行风险 | [`security.md`](./security.md) | 威胁边界、最小权限、敏感数据和安全验证 |
| 语言/技术栈不明确、新项目选型、用户指定技术或技术方向变化 | [`technology.md`](./technology.md) | 从项目证据识别现状，处理用户方向，在边界内自主选型并验证 |
| 多 Agent 编排、任务委派或作为子 Agent 被调用 | [`collaboration.md`](./collaboration.md) | 任务包、单写者与隔离边界、结果返回和主 Agent 验收 |


加载模块后仍以 `core.md` 的目标、证据和验证循环为总控；模块不能替代项目事实或用户授权。
